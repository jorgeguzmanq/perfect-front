Di qué cambiar, justo donde lo ves.

Perfect Front es una capa de comentarios para tu app en desarrollo. Toca un elemento, escribe qué debería cambiar y el comentario queda como un archivo JSON dentro de tu proyecto, listo para una persona o un agente de código.

Ver prototipo de la capa v2 Ver el código

Por qué

El feedback visual vive lejos del código. Aquí se captura donde ocurre y se guarda donde se usa.

Sin tocar tu app

Nada de imports ni plugins. Un proxy inyecta la capa; Vite, Next.js, Angular o HTML estático.

Tu proyecto manda

Un comentario es un archivo en .perfect-front/. Sin nube, sin cuenta, sin base de datos.

Hecho para agentes

CLI con --json estable, bloqueo optimista y códigos de salida documentados.

Con contexto

Selector, archivo y línea, ruta y captura opcional para reencontrar el elemento.

Cómo funciona

Cuatro pasos, desde la raíz de cualquier proyecto.

1

Ejecuta comment

Detecta el proyecto e inicia o reutiliza su dev server.

2

Proxy + capa

Un proxy local inyecta la capa en tu HTML.

3

Alt+clic

Elige un elemento, comenta o márcalo para eliminar. Al guardar, ya puedes elegir otro.

4

Procesa

Dashboard, CLI o un agente leen, reclaman y resuelven.

Capa v2: apuntar, describir, organizar

Regla de diseño: cada zona responde una sola pregunta. Explora el prototipo interactivo →

Apuntar

¿A qué nodos me refiero?

Navegación en cuatro direcciones, selección múltiple, reordenar hermanos y copiar ubicación.

Describir

¿Qué debería cambiar?

Texto e i18n, imágenes (pegar, soltar, abrir) y estilos propuestos «antes → después».

Organizar

¿Con qué otros se entiende?

Grupos con nota de contexto, cola de lectura y cajón de comentarios.

Los cambios se proponen; nunca modifican el código. Todo es previsualizable y reversible.

Inicio rápido

Requiere Node.js ≥ 22 y pnpm ≥ 11.

git clone https://github.com/jorgeguzmanq/perfect-front.git
cd perfect-front
pnpm install && pnpm build

# desde la raíz del proyecto a revisar
perfect-front            # alias: comment
